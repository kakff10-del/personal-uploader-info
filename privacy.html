1. 적용 범위와 목적

이 방침은 Personal YouTube Uploader Windows 프로그램과 앱 소개 사이트에 적용됩니다. 프로그램은 YouTube API Services와 Google OAuth 2.0을 사용하여 사용자가 승인한 채널의 영상 업로드, 상태 조회 및 예약 관리를 수행합니다. 현재 본인 계정·채널을 관리하는 개인용 프로그램이며, 운영자가 다른 사용자의 업로드 데이터를 수집하는 별도 서버는 없습니다.

2. 처리하는 정보와 저장 위치

현재 기본 설치 위치는 D:\YouTubeUploader입니다. 프로그램 폴더 위치를 변경하면 저장 위치도 해당 폴더를 기준으로 바뀝니다.

정보용도와 저장 방식
선택한 영상 파일업로드를 위해 원본 경로에서 읽습니다. 작업 폴더에 영상 사본을 만들지 않습니다. 전송 중 일부 영상 데이터는 메모리에 존재합니다.
채널 ID·이름, 기본 설명, 영상 폴더, 일정채널 선택·기본값 적용에 사용하며 data/uploader.sqlite3에 저장합니다.
파일 경로·크기·SHA-256 해시, 제목·설명, 카테고리, 아동용·합성 여부, 예약 시각, 영상 ID, 진행·실패·처리 상태와 시간중복 방지와 작업 복원·결과 확인에 사용하며 같은 로컬 데이터베이스에 저장합니다. 해시와 전체 로컬 경로를 업로드 API의 별도 필드로 전송하지 않습니다.
OAuth 클라이언트 설정, access token·refresh token, 요청·확인 권한과 연결 식별 정보, 이어 올리기 세션 주소secrets/*.dpapi에 Windows 현재 사용자 기준 DPAPI 암호화로 저장합니다. 정상 로그인과 토큰 갱신에 사용합니다.
가져온 OAuth JSON 원본프로그램은 가져온 뒤 원본 파일을 자동 삭제하거나 암호화하지 않습니다. 사용자가 별도로 보관한 원본 JSON에는 클라이언트 설정과 비밀값이 포함될 수 있습니다.
오류·진단 및 예약 시험 기록logs에 저장합니다. 오류 종류, API 서비스·프로젝트 식별자, 영상·채널 ID, 상태와 확인 시각 등이 포함될 수 있습니다. 예약 시험 기록은 변경 전 영상 제목·설명·상태도 포함할 수 있습니다. 토큰 원문을 기록하도록 구현하지 않았습니다.
로컬 백업·임시·설치 캐시backups, temp, cache를 사용합니다. 개발·복구용 백업에는 채널 설정과 업로드 기록 DB가 포함될 수 있습니다.

DPAPI 암호화는 인증 저장 파일에 적용됩니다. 데이터베이스, 로그, DB 백업 및 가져온 원본 JSON 전체에 적용되는 암호화가 아닙니다. 같은 Windows 계정으로 실행되는 프로그램과 사용자 PC의 접근 권한을 적절히 관리해야 합니다.

3. 외부 전송 및 공유

  • Google 로그인·동의는 사용자의 브라우저에서 이루어집니다. 인증 결과의 코드는 해당 PC의 localhost 임시 주소로 돌아오며, 프로그램은 이를 Google 토큰 서버와 교환합니다. Google 비밀번호나 Chrome 로그인 정보를 읽거나 복사하지 않습니다.
  • 인증 코드·클라이언트 설정·갱신 토큰은 필요한 OAuth 처리에서 Google에 전송됩니다. access token은 Google API 인증과 실제 허용 권한 확인(tokeninfo)에 사용됩니다. Google로의 통신은 HTTPS를 사용합니다.
  • 영상 내용과 사용자가 지정한 메타데이터는 Google/YouTube API로 전송됩니다. 프로그램 운영자용 중계 서버나 별도 클라우드 저장소를 거치지 않습니다.
  • 기존 영상의 예약 변경은 영상 ID와 필요한 상태 정보를 YouTube에 전송합니다. 영상 파일을 다시 업로드하지 않습니다.
  • 프로그램 자체에 광고, 분석 SDK, 데이터 판매, 자동 진단 보고 또는 AI 서비스로의 영상 전송 기능은 없습니다. 사용자가 문의를 위해 이메일을 보내면 이메일 주소·문의 내용·직접 첨부한 자료는 문의 응대에 사용됩니다.

Google/YouTube가 처리하는 데이터에는 Google 개인정보처리방침과 YouTube 서비스 약관이 적용됩니다. 위 링크는 외부 처리자의 안내이며 이 앱의 방침을 대신하지 않습니다.

4. 보관 기간과 삭제

현재 프로그램에는 채널 인증·업로드 기록·일반 진단 파일을 일정 기간 후 일괄 자동 삭제하는 기능이 없습니다. 재시작 후 작업 복원과 중복 방지를 위해 사용자가 로컬 데이터를 정리할 때까지 남습니다. 앱 로그는 파일당 약 1 MiB 기준으로 순환하며 이전 파일을 최대 3개 보관하지만, 별도 진단 JSON·시험 로그·백업에는 이 순환 규칙이 적용되지 않습니다.

Google 권한 철회나 토큰 만료가 로컬 데이터의 자동 삭제를 의미하지 않습니다. 현재 화면에는 채널별 전체 데이터 삭제 기능이 없으며, 전송 이력이 있는 업로드 행의 삭제도 중복 방지 때문에 제한됩니다.

  1. 진행 중인 업로드와 예약 시험·복구 작업을 먼저 종료 또는 확인한 뒤 프로그램을 닫습니다.
  2. Google 계정의 서드 파티 연결 관리에서 이 앱의 접근 권한을 철회할 수 있습니다.
  3. 앱의 로컬 데이터를 모두 삭제하려면 설치 폴더의 secrets, data, logs, 관련 backups, temp, cache와 별도로 보관한 OAuth JSON·진단 사본을 정리해야 합니다. 특정 채널만 삭제하려면 문의하여 대상과 범위를 확인하세요. 이 문서는 삭제를 실행하지 않습니다.

인증·기록 삭제 후 연결 복원이나 중복 업로드 감지가 불가능해질 수 있습니다. 원래 위치의 영상과 YouTube에 업로드된 영상은 로컬 데이터 삭제만으로 지워지지 않습니다. YouTube 영상 삭제·예약 취소는 YouTube Studio에서 별도로 관리할 수 있습니다. 사용자 보유 백업과 휴지통도 필요한 경우 별도로 정리해야 합니다.
