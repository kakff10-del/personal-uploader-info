내 PC에서 선택하고,
YouTube 공식 API로 업로드합니다.

Personal YouTube Uploader는 본인이 관리하는 YouTube 채널에 영상을 업로드하고, 기존 영상의 예약 게시를 조회·변경·취소하는 Windows용 개인 프로그램입니다. 운영자는 송근철이며, 현재 본인 계정과 채널의 관리에 사용합니다.

개인정보처리방침 읽기

주요 기능

  • Google OAuth 로그인 후 실제 채널 ID와 이름을 확인합니다.
  • 영상 파일, 제목·설명, 아동용 여부, 변경·합성 콘텐츠 여부, 한국 시간의 예약 시각을 확인하고 업로드합니다.
  • 채널별 기본 설명·영상 폴더·공개 일정을 저장하고, 채널과 파일 해시를 이용해 중복 업로드를 방지합니다.
  • 진행 상황과 실패 이유, YouTube 처리·예약 상태를 구분해 표시합니다.
  • 기존 영상은 재업로드하지 않고 영상 ID로 예약 등록·시간 변경·예약 취소 후 비공개 유지를 요청합니다.

예약 게시 기능은 서버에서 수락되고 실제 반영됐는지 별도로 확인합니다. 기능 제공이 모든 채널의 게시 가능 여부를 보장하는 것은 아닙니다.

데이터 처리 방식

선택한 영상은 원래 위치에서 읽어 HTTPS로 Google/YouTube에 직접 전송합니다. 영상 원본을 작업 폴더에 중복 복사하거나 운영자 서버에 업로드하지 않습니다.

기본 설치 위치는 D:\YouTubeUploader입니다. 인증 정보는 Windows DPAPI로 암호화한 로컬 파일에 저장합니다. 채널 설정·업로드 기록·진단 로그는 별도 로컬 파일에 저장되며 전체 폴더가 암호화되는 것은 아닙니다. 이 소개 사이트는 업로더의 데이터 수집 서버가 아닙니다.

Google 계정 권한

OAuth 범위사용 목적
youtube.upload선택한 영상 업로드
youtube.readonly연결 채널과 영상 상태 확인
youtube.force-ssl기존 영상의 공개 설정·예약 시각 등 수정

범위의 공통 접두사는 https://www.googleapis.com/auth/입니다. force-ssl은 넓은 YouTube 편집 권한을 포함하지만, 현재 프로그램에 영상 삭제나 댓글 관리 기능은 없습니다. Google 비밀번호를 프로그램에 입력하거나 저장하지 않습니다.

이용 안내

사용자는 업로드할 영상에 필요한 권리를 확보하고 본인이 관리할 권한이 있는 채널을 연결해야 합니다. 이 앱은 YouTube API Services를 사용하며, 앱을 이용할 때 YouTube 서비스 약관이 적용됩니다. 데이터 처리 내용은 이 앱의 개인정보처리방침을 확인하세요.

로컬 업로드·상태 확인·자동 복구 작업은 PC 및 인터넷 연결이 필요합니다. 강제 종료·정전·네트워크 장애 시 실행 시각이나 복구 완료를 보장하지 않습니다. YouTube에 정상 등록된 예약은 YouTube가 처리합니다.
